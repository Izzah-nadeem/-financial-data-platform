# Financial Data Platform

A data engineering project focused on building an end-to-end platform for ingesting, transforming, and analyzing financial market data.

The project begins with live market data from Yahoo Finance and will progressively evolve into a Databricks-based data platform using Apache Spark and Delta Lake.

## Planned Tech Stack

- Python
- Databricks
- Apache Spark
- Delta Lake
- yfinance
- Git & GitHub

> 🚧 This project is under active development.
